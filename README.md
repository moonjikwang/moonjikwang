I build self-hosted infrastructure tools that are simple to run and safe to put on the internet.

#### 🐦 [Corvus](https://github.com/corvus-gateway/corvus): open-source reverse proxy with a WAF

An Nginx Proxy Manager-style console with Let's Encrypt, plus the security you would otherwise bolt on:
WAF rules, automatic IP bans, a browser challenge, an "under attack" mode, a waiting room for traffic
spikes, and a live traffic monitor. One container (OpenResty + Go), amd64/arm64, Apache-2.0.
